
# Smart Parking System Using VHDL

## Overview
A smart parking system designed using VHDL and simulated with ModelSim.

## Features
- Vehicle entry and exit detection
- Vehicle counting with capacity control
- Parking full and empty indicators
- Entry and exit barrier control
- Seven-segment display output
- VHDL testbench for simulation

## Project Structure
- `src/`: VHDL design files
- `sim/`: Testbench and simulation files

## Tools Used
- VHDL
- ModelSim

## Simulation
The testbench generates the clock and reset signals and simulates vehicle entry and exit scenarios to test the parking system.
